# Certificates Directory

This directory should contain your actual certificate and award files.

## Expected Files:

### Awards & Certificates (PDF/PNG format):
- `iit-kanpur-gold-certificate.png` - IIT Kanpur Gold Developer Certificate (image format)
- `iit-kanpur-gold-certificate.pdf` - IIT Kanpur Gold Developer Certificate (PDF format for download)
- `tcs-on-spot-awards.pdf` - TCS On-the-Spot Awards certificate
- `tcs-best-team-award.pdf` - TCS Best Team Performance award
- `aws-cloud-practitioner.pdf` - AWS Cloud Practitioner certification
- `azure-az900.pdf` - Microsoft Azure AZ-900 certification
- `ijraset-paper.pdf` - Downloaded copy of IJRASET research paper (optional)

## File Naming Convention:
- Use lowercase letters and hyphens for consistency
- Include the organization and certificate type in the filename
- Support both PDF and image formats (PNG/JPG)

## Usage:
The ModalView component will display these files when users click "View Certificate" or "View Award" buttons in the Awards section.

## Security Note:
Only add files you're comfortable sharing publicly, as these will be accessible via your website.
